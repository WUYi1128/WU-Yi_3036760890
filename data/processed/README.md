# Processed Data

This directory is used for cleaned and processed data generated by the replication workflow.

The main processed dataset is:

`data/processed/analysis_sample.csv`

This file is generated automatically from the course-provided raw dataset by:

`code/02_clean_data.py`

Because `analysis_sample.csv` is derived at the restaurant level from the course-provided dataset, it is not distributed through this public GitHub repository.

To reproduce the processed dataset:

1. Obtain the Card and Krueger (1994) dataset provided as part of the ECO6067 course materials.
2. Save the raw dataset using the exact path and filename:

   `data/raw/public.csv`

3. Run the complete reproduction workflow from the repository root:

   `python code/run_all.py`

Alternatively, the data-cleaning stage can be run directly using:

   `python code/02_clean_data.py`

The cleaning script constructs the processed analysis sample and saves it automatically as:

`data/processed/analysis_sample.csv`

No manual editing of the processed dataset is required.

The processed dataset is used by the subsequent replication, validation, and independent-extension scripts. Final aggregated tables and figures generated from the analysis are retained in the `outputs/` directory.
