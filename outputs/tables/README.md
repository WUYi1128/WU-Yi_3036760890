# Tables

This directory contains the final numerical outputs generated by the empirical replication, validation, and independent-extension workflow for the ECO6067 project based on Card and Krueger (1994).

All files in this directory are generated automatically by the Python scripts in the `code/` directory. No manual editing of the output tables is required.

---

## 1. `table2_replication.csv`

This file contains the replication of selected results from Table 2 of Card and Krueger (1994).

The table reports descriptive statistics for New Jersey and Pennsylvania restaurants across the two survey waves, including employment, wages, store characteristics, and other selected variables.

It is generated by:

`code/03_replicate_table2.py`

Key replicated full-time-equivalent employment values include:

| Statistic | Replication | Published benchmark |
|---|---:|---:|
| Wave 1 NJ FTE | 20.439 | 20.44 |
| Wave 1 PA FTE | 23.331 | 23.33 |
| Wave 2 NJ FTE | 21.027 | 21.03 |
| Wave 2 PA FTE | 21.166 | 21.17 |

The small differences are due to rounding and are within the numerical validation tolerances used in the project.

---

## 2. `table3_replication.csv`

This file contains the replication of selected employment-change and difference-in-differences results associated with Table 3 of Card and Krueger (1994).

It is generated by:

`code/04_replicate_table3.py`

The main replicated results include:

| Result | Replication | Published benchmark |
|---|---:|---:|
| Main DiD estimate | 2.754 | 2.76 |
| Balanced-sample DiD | 2.750 | 2.75 |
| Temporary-closure sensitivity | 2.509 | 2.51 |

The close agreement between the replicated and published values indicates that the sample construction and employment definitions reproduce the main empirical result accurately.

---

## 3. `table4_replication.csv`

This file contains the replication of selected reduced-form employment regression results associated with Table 4 of Card and Krueger (1994).

It is generated by:

`code/05_replicate_table4.py`

The estimation sample contains 357 restaurants.

Selected replicated coefficients are:

| Model | Main coefficient | Replication | Published benchmark |
|---|---|---:|---:|
| (i) | NJ indicator | 2.326 | 2.33 |
| (ii) | NJ indicator | 2.304 | 2.30 |
| (iii) | GAP | 15.653 | 15.65 |
| (iv) | GAP | 14.916 | 14.92 |
| (v) | GAP | 11.979 | 11.91 |

The first four specifications reproduce the published values very closely.

Model (v) shows a somewhat larger numerical difference, but the replicated value remains close to the published estimate and is within the tolerance adopted in the validation script.

## 4. `figure1_wage_distribution.csv`

This file contains the numerical wage-distribution data used to generate the replicated Figure 1.

It is generated by:

`code/06_replicate_figure1.py`

The file records the percentage distribution of observed starting wages for New Jersey and Pennsylvania in:

- Wave 1: February 1992;
- Wave 2: November 1992.

A key replicated feature is the concentration of New Jersey Wave 2 starting wages at the new minimum-wage level of $5.05.

Approximately 89.62% of the non-missing New Jersey Wave 2 starting-wage observations are concentrated at this wage level.

The corresponding figure is stored in:

`outputs/figures/figure1_wage_distribution.png`

## 5. `validation_summary.csv`

This file contains the automated numerical validation results for the core replication.

It is generated by:

`code/07_validation.py`

The validation script compares the main replicated results with benchmark values from the original study.

The final validation run reported:

```text
Passed checks: 13/13
All core replication checks passed.
```

The checks cover key quantities from:

- Table 2;
- Table 3;
- Table 4;
- Figure 1.

Each validation test records:

- the replicated value;
- the benchmark value;
- the numerical difference;
- the tolerance used;
- whether the check passed.

## 6. `extension_chain_did.csv`

This file contains the main results from the independent extension.

The extension asks:

> Did the employment response to New Jersey's minimum-wage increase differ across restaurant chains?

It is generated by:

`code/08_extension.py`

The analysis estimates chain-specific difference-in-differences effects for:

- Burger King;
- KFC;
- Roy Rogers;
- Wendy's.

The estimated chain-specific DiD effects are:

| Restaurant chain | NJ observations | PA observations | Chain-specific DiD |
|---|---:|---:|---:|
| Burger King | 126 | 33 | 4.390 |
| KFC | 67 | 12 | -1.594 |
| Roy Rogers | 77 | 17 | 2.488 |
| Wendy's | 39 | 13 | 3.417 |

The associated figure is stored in:

`outputs/figures/extension_chain_did.png`

These estimates should be interpreted cautiously because the individual chain-level estimates are relatively imprecise.

---

## 7. `extension_chain_heterogeneity_test.csv`

This file contains the joint heterogeneity test associated with the independent extension.

It is also generated by:

`code/08_extension.py`

The test evaluates whether the employment response differs systematically across restaurant chains.

The reported test statistics are:

| Statistic | Value |
|---|---:|
| F-statistic | 2.602 |
| p-value | 0.0518 |

At the conventional 5% significance level, the null hypothesis of no systematic chain-level heterogeneity is not rejected.

The result is close to the 5% threshold, so it should be interpreted as suggestive but not as strong evidence that the employment effects differ systematically across restaurant chains.

## Reproducing the Tables

The complete workflow can be executed from the repository root using:

```bash
python code/run_all.py
```

Before running the workflow, the course-provided raw dataset must be placed at:

```text
data/raw/public.csv
```

The raw dataset itself is not included in this public GitHub repository.

The master script automatically performs:

1. raw-data inspection;
2. data cleaning and variable construction;
3. replication of Table 2;
4. replication of Table 3;
5. replication of Table 4;
6. replication of Figure 1;
7. automated validation;
8. the independent restaurant-chain extension;
9. generation of the final numerical outputs and figures.

No manual modification of the raw or processed data is required once the course-provided input dataset has been placed in the expected location.

## Data and Output Policy

The public repository contains only aggregate analytical outputs required to document and reproduce the empirical results.

The following restaurant-level datasets are intentionally excluded from the public repository:

```text
data/raw/public.csv
data/processed/analysis_sample.csv
```

The raw dataset was provided as part of the ECO6067 course materials, and the processed dataset is a restaurant-level derivative of that input.

Users with authorised access to the course-provided dataset can reproduce all files in this directory by placing the raw CSV file at:

```text
data/raw/public.csv
```

and running:

```bash
python code/run_all.py
```
