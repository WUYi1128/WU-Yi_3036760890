# Figures

This directory contains the final figures generated by the empirical replication and independent-extension workflow for the ECO6067 project based on Card and Krueger (1994).

All figures are generated automatically by the Python scripts in the `code/` directory. No manual editing of the figures is required.

---

## 1. `figure1_wage_distribution.png`

This figure reproduces the main pattern of Figure 1 in Card and Krueger (1994).

It compares the distribution of starting wage rates in New Jersey and Pennsylvania across the two survey waves:

- Wave 1: February 1992;
- Wave 2: November 1992.

The figure is generated by:

`code/06_replicate_figure1.py`

The numerical wage-distribution data used to construct the figure are saved in:

`outputs/tables/figure1_wage_distribution.csv`

### Replication result

The replicated Figure 1 shows the main wage-distribution pattern documented in the original study.

In particular, after New Jersey increased its minimum wage to $5.05, approximately 89.62% of the non-missing New Jersey Wave 2 starting-wage observations were concentrated at the $5.05 wage level.

This strong concentration around the new minimum wage is consistent with the principal pattern shown in the original Card and Krueger analysis.

The figure should therefore be interpreted as a replication of the distributional pattern rather than as an attempt to reproduce every graphical detail of the published figure exactly.

## 2. `extension_chain_did.png`

This figure presents the independent extension of the replication project.

The extension investigates the following research question:

> Did the employment response to New Jersey's minimum-wage increase differ across restaurant chains?

The analysis compares employment changes for Burger King, KFC, Roy Rogers, and Wendy's restaurants in New Jersey and Pennsylvania.

For restaurant \(i\), the change in full-time-equivalent employment is defined as:

```math
\Delta \mathrm{FTE}_i
=
\mathrm{FTE}_{i,2}
-
\mathrm{FTE}_{i,1}
```

where:

- \(\mathrm{FTE}_{i,1}\) is full-time-equivalent employment in Wave 1;
- \(\mathrm{FTE}_{i,2}\) is full-time-equivalent employment in Wave 2.

For restaurant chain \(c\), the chain-specific difference-in-differences estimate is:

```math
\widehat{\mathrm{DiD}}_c
=
\overline{\Delta \mathrm{FTE}}_{NJ,c}
-
\overline{\Delta \mathrm{FTE}}_{PA,c}
```

where:

- \(\overline{\Delta \mathrm{FTE}}_{NJ,c}\) is the average employment change for chain \(c\) in New Jersey;
- \(\overline{\Delta \mathrm{FTE}}_{PA,c}\) is the corresponding average employment change for chain \(c\) in Pennsylvania.

The figure is generated by:

`code/08_extension.py`

The corresponding numerical results are saved in:

- `outputs/tables/extension_chain_did.csv`
- `outputs/tables/extension_chain_heterogeneity_test.csv`

### Chain-specific results

The estimated chain-specific DiD effects are:

| Restaurant chain | Chain-specific DiD |
|---|---:|
| Burger King | 4.390 |
| KFC | -1.594 |
| Roy Rogers | 2.488 |
| Wendy's | 3.417 |

The figure displays these chain-level estimates together with their estimated uncertainty.

The point estimates differ across restaurant chains, but the individual estimates are imprecise and should not be interpreted as definitive evidence of heterogeneous treatment effects.

### Joint heterogeneity test

A joint test was also conducted to assess whether the employment response differed systematically across restaurant chains.

The test produced:

- F-statistic = 2.602
- p-value = 0.0518

At the conventional 5% significance level, the null hypothesis of no systematic chain-level heterogeneity is not rejected.

Therefore, the data do not provide sufficiently strong evidence at the 5% level that the employment response to New Jersey's minimum-wage increase differed systematically across restaurant chains.

However, because the p-value is close to 0.05, the result should be interpreted cautiously rather than as strong evidence of complete homogeneity.

## Reproducing the Figures

The complete project workflow can be executed from the repository root using:

```bash
python code/run_all.py
```

Before running the workflow, the course-provided raw dataset must be placed at:

```text
data/raw/public.csv
```

The raw dataset is not included in this public GitHub repository because it was provided as part of the ECO6067 course materials.

The master script automatically performs:

1. raw-data inspection;
2. data cleaning and variable construction;
3. replication of Tables 2, 3, and 4;
4. replication of Figure 1;
5. numerical validation of the core replication results;
6. the independent restaurant-chain extension;
7. generation of the final tables and figures.

No manual modification of the raw or processed data is required after the course-provided input file has been placed in the expected location.

## Data and Output Policy

Only aggregate analytical outputs and final figures are retained in this public repository.

The following restaurant-level datasets are intentionally excluded:

```text
data/raw/public.csv
data/processed/analysis_sample.csv
```

The first is the course-provided raw dataset, while the second is a derived restaurant-level analysis dataset generated by the cleaning workflow.

Both files can be reconstructed or supplied locally for replication, but they are not distributed through the public GitHub repository.

The aggregated tables and figures in `outputs/` are retained because they represent analytical results rather than redistributed restaurant-level course data.
