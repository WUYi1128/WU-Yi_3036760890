# Figures

This directory contains the figures generated by the empirical replication and independent-extension workflow.

All figures are produced automatically by the Python scripts in the `code/` directory. No manual editing of the figures is required for replication.

## 1. `figure1_wage_distribution.png`

This figure reproduces the main pattern of Figure 1 in Card and Krueger (1994).

It compares the distribution of starting wage rates in New Jersey and Pennsylvania across the two survey waves:

- Wave 1: February 1992;
- Wave 2: November 1992.

The figure is generated by:

`code/06_replicate_figure1.py`

The underlying numerical distribution used to construct the figure is saved in:

`outputs/tables/figure1_wage_distribution.csv`

A key validation result is that approximately 89.62% of observed New Jersey Wave 2 starting wages are concentrated around the $5.05 minimum-wage level, which is consistent with the main pattern reported in the original study.

## 2. `extension_chain_did.png`

This figure reports the independent extension of the replication project.

The extension asks whether the employment response to New Jersey's minimum-wage increase differed across restaurant chains.

Chain-specific difference-in-differences estimates are calculated using the change in full-time-equivalent employment between the two survey waves.

For restaurant chain \(c\), the chain-specific difference-in-differences estimate is:

\[
\widehat{DiD}_c
=
\left(
\overline{\Delta FTE}_{NJ,c}
\right)
-
\left(
\overline{\Delta FTE}_{PA,c}
\right),
\]

where

\[
\Delta FTE_i
=
FTE_{i,2}
-
FTE_{i,1}.
\]

The figure is generated by:

`code/08_extension.py`

The corresponding numerical results are saved in:

- `outputs/tables/extension_chain_did.csv`
- `outputs/tables/extension_chain_heterogeneity_test.csv`

The extension also conducts a joint heterogeneity test across restaurant chains. The estimated test produced:

- F-statistic = 2.602;
- p-value = 0.0518.

Therefore, at the conventional 5% significance level, the analysis does not provide strong evidence that the employment response differs systematically across restaurant chains, although the result is close to the 5% threshold and should be interpreted cautiously.

## Reproducing the Figures

The complete set of figures can be regenerated from the project root by running:

`python code/run_all.py`

The required course-provided raw dataset must first be placed at:

`data/raw/public.csv`

The raw dataset itself is not included in this public repository.

Running the master script reconstructs the processed data, replication tables, validation results, independent-extension results, and final figures automatically.

## Output Policy

Only final aggregate analytical outputs and figures are stored in this public repository.

Course-provided raw data and derived restaurant-level processed data are excluded from the repository.
