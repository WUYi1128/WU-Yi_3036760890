# Reusable Replication Skill

## Purpose

This skill documents the reusable workflow used to generate the main tables and figures in the ECO6067 replication project.

## Workflow

1. Load the original data.
2. Validate the raw data.
3. Clean and process the sample.
4. Construct the required variables.
5. Reproduce the main empirical results.
6. Generate the required tables and figures.
7. Compare the replication results with the original paper.
8. Conduct validation and robustness checks.
9. Run the independent extension.
10. Export all final outputs.
